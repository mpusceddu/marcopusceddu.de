# Mail-Signaturen 2026

Bilddateien der von Marco freigegebenen privaten, politischen und geschäftlichen Mail-Signaturen. Der Branch mail-signaturen-2026 wird dauerhaft als Bildquelle verwendet und darf nicht gelöscht werden. Die Signaturen verweisen auf den unveränderlichen Commit.

Nur Bildzeichen und Kontakt-Icons werden hier bereitgestellt. HTML-Signaturen und Kontaktdaten bleiben im lokalen Signaturpaket. Die Website auf main bleibt unverändert.
